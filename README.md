# Umbrella Match Graphic

A self-contained, client-side football graphic generator for GitHub Pages.

Files can be uploaded directly to the repository root; there is no `assets` folder and no build step.

The generated graphic is 1080 × 1920 PNG.

The stainless-steel and diamond-plate preview textures use the two texture URLs supplied for this project. If a browser blocks a third-party texture during PNG export, the exporter automatically falls back to local procedural metal textures so the download still works instead of breaking.
