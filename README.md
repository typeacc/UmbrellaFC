# Umbrella Football Match Graphics Terminal

A fully client-side football match graphic generator for GitHub Pages.

## Use
1. Extract the ZIP.
2. Drag the website files/folders into the root of a GitHub repository.
3. Enable GitHub Pages.
4. Open the site and select a match photo.
5. Edit the match information and scorers.
6. Adjust image position if needed.
7. Click **DOWNLOAD GRAPHIC**.

No Node.js, npm, backend, database, API key, or server is required.

All image processing and PNG rendering happen in the browser.
